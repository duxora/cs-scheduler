## What changed
- `apps/splanner/connectors/life_graph.py` (new) — read-only sqlite on `~/.life-graph/life-graph.db`; polls signal entity types only (decision/goal/commitment/lesson/idea — knowledge/person/context excluded as reference noise), 50/poll cap; signals go through the S5 classify pipeline
- `apps/splanner/capture.py` (new) — `ingest_connector()` extracted from the poll route (route + daemon share it); `capture_daemon_loop()`: 60s tick, daily capture pass at 08:00 (per-connector try/except — one failure never blocks the rest; unconfigured connectors skipped at debug level), per-connector watermarks + state in `DATA_DIR/splanner-daemon-state.json`
- Monday 08:30 digest cron via `should_draft_digest()` — skips when an approved digest already exists for the week; `digest.draft_and_store()` extracted and reused by the route
- `server/main.py` — lifespan starts/cancels the daemon task (`SPLANNER_DAEMON=0` to disable)

## Key decisions
- Entity-type allowlist as noise control on life-graph ingestion
- Behavior-preserving refactors: poll route and digest-draft route now delegate to the shared helpers; existing suites unchanged (one S8 registry test updated — it asserted the exact connector list, which any new connector necessarily extends; rewritten as membership + deterministic configured flags)
- Daemon watermark file separate from DB-derived ingestion `since` — dedup by (source, source_ref) keeps overlap safe
